# Project Memory

## Core
UniBluePrint — Irish student platform. "The Structure Behind Your Success."
Tone: structured and premium, NOT hype. No casual greetings like "Hey [name], ready to level up."
6 user types: university student, 5th year, 6th year, apprentice, young worker, other young person.
Design: bg white (#FFFFFF) / navy (#0A1628), primary #1A3FBF, accent #4A6FE3, Inter font.
Tech: React, Supabase, Cloudflare R2, Stripe Elements, GitHub.
Bottom nav: Home, Blueprint, Connect, Lifestyle, More.
Three portals: Student app, Handler/Coach (/portal), Operations (/operations).
All payments flow through UniBluePrint company account first — never direct to providers.
